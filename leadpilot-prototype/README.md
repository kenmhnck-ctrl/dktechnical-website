# LeadPilot v0.1

AI集客事業の実証用プロトタイプ。

## 初期目標
- DKを実証1号として運用
- 写真・現場情報からSNS/Google/HP向けコンテンツを生成
- 問い合わせ→見積→受注→売上を追跡
- 有料継続100社を3〜4か月で狙う
- 初期固定費は月3万円以内を目安

## 実装順
1. 販売LP + DK実証ダッシュボード
2. 本物のAIコンテンツ生成API接続
3. DKサイトへの問い合わせ計測導線
4. SNS/Google投稿連携
5. CRM・AI追客
6. 無料AI集客診断
7. LeadPilot自身の営業自動化
8. 代理店/紹介販売機能

## KPI
投稿数ではなく、問い合わせ・見積・受注件数・受注金額・流入元を主要KPIとする。
